UI 库选型以及依赖安装

针对YAT自主品牌全球经销商门户系统项目，其基于Nuxt 3、以展示为主、对UI定制化要求极高以及采用原子化CSS方案的特性，本报告的结论是：
首选推荐：Nuxt UI 与 Headless UI 的组合
这一组合提供了最佳的平衡点：
●Nuxt UI作为核心UI框架，凭借其与Nuxt 3的深度原生集成、全面的组件集和灵活的设计系统，能够高效地构建门户网站的大部分内容，并提供系统化的深度定制能力。它在默认样式和细粒度控制之间取得了良好的平衡，加速了开发进程，同时确保了品牌一致性。
●Headless UI作为定制化利器，专为处理那些需要绝对控制的复杂、独特UI交互而设计。其纯粹的无样式特性与原子化CSS完美契合，确保了在最关键的定制化需求上，设计能够像素级完美地实现，而没有任何框架层面的限制。
这种分层策略能够满足项目“极高定制化”的核心要求，同时兼顾开发效率、可维护性和长期稳定性，避免了单一库可能带来的局限性，以及混合多个大型UI库可能引发的集成冲突。
●Shadcn/Vue： 若团队具备强大的设计系统构建能力和充足的资源，愿意承担组件代码的长期维护责任，Shadcn/Vue提供极致的定制自由度。
